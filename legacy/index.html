CorpLang docs

CorpLang is a tiny toy language: every line is rewritten into one line of Python by a list of regular-expression rules. Blocks use Python's own indentation — indent with 4 spaces just like Python.

Running it

  • This page: just open index.html in a browser. If Pyodide fails to load from file://, serve the folder instead: python -m http.server then visit http://localhost:8000.
  • Command line: python corplang.py example.corp (add --show to print the generated Python).

Anything with no matching rule (expressions, function calls, operators, string literals) passes through to Python unchanged, so range(), arithmetic, comparisons, f-strings, etc. all just work. ALIGN, SYNERGY, LOCKED IN and friends are only swapped in code, so those words survive untouched inside strings and # comments.

Blocks & indentation

There is no block terminator. A header line ending in : (produced by TOUCH BASE, FOR EACH, DELIVERABLE…) opens a block; indent the body 4 spaces. THANKS is optional sugar that reads like the end of an email — it is deleted before Python sees it.

Known limitations.
  • No type system, and none on the roadmap.
  • Execution is synchronous. An infinite loop (CIRCLE BACK LOCKED IN with no TAKE THIS OFFLINE) will freeze the tab — reload to recover.
  • No sandbox: transpiled code runs with the full Pyodide standard library.
